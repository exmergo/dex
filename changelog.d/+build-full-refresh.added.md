**`transform build --full-refresh` rebuilds an incremental model after its logic changes.** An incremental run keeps the rows the old logic wrote, so the flag passes dbt's `--full-refresh`, on the dev target only. The cost preflight prices each selected incremental model as the full rebuild that runs (on BigQuery, with no upper-bound lines). `data.full_refresh` names the models and seeds rebuilt, and any a `full_refresh: false` config keeps from rebuilding. `data.evidence.invocation.full_refresh` records the flag. A full refresh with no `--select` warns with the count of what it rebuilds.
