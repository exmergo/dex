**A Metric View whose query source aggregates its rows no longer claims the table as its relation.** A source such as `SELECT sum(b) AS a FROM t`, or one with a `HAVING` and no `GROUP BY`, returns one row rather than one row per row of `t`, but the view still claimed `t` as its relation, feeding the wrong relation to the catalog, the PII gate, and the `maintain` schema and grain axes. Such a source now claims no relation, and the note says why, as for a `GROUP BY`. A window function keeps the row count, so a source that only windows its columns still claims its table.
