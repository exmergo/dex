**Warn when the installed Elementary release ignores the sampling flag.** Elementary honors `disable_test_samples` only from package 0.20.0 onwards. When Dex renders a test with the flag into a project where Elementary's test materialization is active and the installed package release is below 0.20.0 (or indeterminate), the result carries a warning naming the installed release, explaining that the flag has no effect, and advising either to upgrade the package to 0.20.0 or later or set `test_sample_row_count: 0` for the project (#1381).
