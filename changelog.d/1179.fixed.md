**`source()` in an attribution resolves by its declared relation.**
A source whose table `identifier` differs from its logical name no longer
reports `unprofiled_input` under a name nothing carries: the project's
declared relation is tried first, then the bare object name, and a declared
relation whose `schema`, `database` or `identifier` carries Jinja is refused
outright instead of bare-name matching a cached table the declaration never
pointed at.
