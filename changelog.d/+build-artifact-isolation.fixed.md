**Dex's dbt builds no longer write the project's shared `target/`, so a project or CI runtime of another dbt version no longer fails on what they left behind.** Every dbt invocation a build runs (the build, the compile that prices it, the seed check) now writes `<target-path>/dex/<dbt-version>/`, and `data.artifact_directory` names it. This prevents, for example, dbt 1.10 raising `IsADirectoryError` on a snapshot path dbt 1.12 left as a directory. `transform.artifacts: shared` writes the project's own target path instead, and refuses one another runtime left incompatible rather than writing over it or deleting anything. The target path honors `DBT_TARGET_PATH` and `target-path` in `dbt_project.yml`. Every manifest reader takes the newer of Dex's directory and the project's own. A `run_results.json` from another dbt invocation is never reported as the build's success.
