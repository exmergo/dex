`transform build --verify --for-plan` now measures what a plan did to the models below its edits (#1231). The models the plan rewrote and every unedited model below them are re-executed against the tree before the plan, which `transform apply` now records on the plan as `baseline_sources` (else the git `HEAD` blob whose hash the plan recorded). Per model, `data.verification.impact` counts rows and keys on each side (kept, removed, added, duplicated; keys compared as text, so a retyped key still matches) and, on a mart, the kept keys each column changed on; counts and names only. An unedited model whose rows or keys moved is a `downstream_population_changed` finding naming the edit upstream, attributed `introduced`, and an `unverified` reason that keeps the build from reading `validated`, unless its declaration records the population as an assumption at `request` or `contract` tier. `data.completion.impact` leads with the largest changes. On billed connectors the statements are priced with the build as `(downstream impact)`, and a model above a quarter of the command ceiling is `unchecked: cost`. `data.change_scope.downstream` names, at plan time and for free, the unedited models below each rewrite.
