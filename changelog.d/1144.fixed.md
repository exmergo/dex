**Generated dbt unit tests for incremental models without an `is_incremental()` branch now include the required `is_incremental: false` macro override.**
dbt requires an `is_incremental` macro override for every unit test of an incremental model, even when the model SQL does not contain an explicit incremental branch. dex previously omitted this override when no incremental block was present in SQL, causing dbt unit test parsing to fail. dex now resolves model materialization and includes `is_incremental: false` in the generated full-build test.
