**Tests gated on an optional extra now skip instead of failing when the extra is not installed.** Five tests imported their extra's modules before the skip guard ran, so a contributor running the suite with only the `dev` and `duckdb` extras saw failures: the BigQuery reserve tests imported the fake client (which needs `google.api_core`) ahead of the `importorskip`, and the hosted semantic-layer tests reached the backend, which raises for the missing `[semantic-api]` extra, before any skip. They now skip with a reason naming the extra, and still run with every extra installed (#1501).
