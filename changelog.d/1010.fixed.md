**`maintain reconcile` returns advisory proposals in native-only repositories when the layer handles none of the findings.** Rather than refusing with a missing dbt project error, a repository configuring only a native semantic layer (Ossie, SLayer, Cube) reconciles unhandled findings (such as declared grain violations or volume changes) as advisory proposals with no stored plan when no transformation project is present. An invalid transformation project on disk continues to refuse as an error.
