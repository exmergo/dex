**Establish build completion and coverage for plans that only add dbt tests.** `required_nodes` now resolves singular test edits (`EditKind.TEST_SQL`) and native unit test definitions (`unit_tests:` in schema YAML) to their expected test nodes, including across configured test paths. Build completion recognizes passing and warning test runs as satisfied test deliverables without conflating test execution with model rebuilds. Skipped, disabled, failed, or missing tests are reported explicitly and prevent validated completion, while unrelated model builds report `unrelated` outcome.
