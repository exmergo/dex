**The `[slayer]` extra now pins SLayer 1.8.2 (was 1.2.0).** The model format is still version 15, so existing SLayer model files read unchanged. Two behaviours follow SLayer's own: a metric query renders the model's filters in a subquery under the query's filter (the same rows, a different statement shape), and a declared column whose warehouse type moved to another bucket (`declared_type_conflict` from `maintain schema`) is now reported with SLayer's remedy (`remedy_kind`, `remedy`) instead of a removal, so `maintain reconcile` proposes changing the declared type as advisory rather than cutting the column and the measures on it. Installing the extra now resolves SQLAlchemy below 2.1, which SLayer 1.8 requires.
