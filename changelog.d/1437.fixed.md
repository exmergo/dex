**A local semantic read says when the compiled manifest is older than the YAML.** `transform apply` writes semantic YAML and leaves `semantic_manifest.json` as it was, so until `dbt parse` ran, `explore semantic list` silently returned the old layer and `explore semantic query` of a metric applied a moment ago failed as if its name were a typo. A local list, values or query now warns, naming the semantic YAML files newer than the manifest and `dbt parse`, and its refusal of an unknown metric or dimension, or a query that fails to resolve, carries the same note (#1269, #1417).
