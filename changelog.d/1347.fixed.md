`maintain coverage` now annotates each source's freshness check with its last run status, read from the newest `sources.json` in the same artifact directories the run-results reader uses. The freshness run is reported apart from the test run as `data.freshness_run`, with its own invocation, generated time and age, and is never worded as current. With no `sources.json`, a note says so; nothing from a result row but its id and status is read.
