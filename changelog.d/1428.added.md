**`transform plan` lists the tests a plan removes.** A plan that rewrote a model's YAML as a stub deleted its `unit_tests:` block with no warning, and nothing else at plan time noticed (#1420). `data.change_scope.removed_tests` now names each unit test, data test (on a model or one of its versions, a snapshot, a seed or a source table, and on a column) and singular test the plan removes, by name and what it tests, with the path it was read from, and a `warnings` line lists them. It covers a deleted YAML block, a rewritten YAML file and a deleted test file. Editing a test, moving it to another file, or carrying it to a model the plan renames is not a removal. The plan is still stored: keep the test, or say the request asks to drop it.
