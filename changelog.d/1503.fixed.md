**A versioned deliverable a plan names by its file stem is `asserted` when a test checked it.** With `--for-plan`, a deliverable may be the version's file stem (`dim_customers_v2`) while a test names its model by label (`dim_customers.v2`), so a version a passing test checked read `build_only`, and one a failing test checked was missing from `failed_checks`. `data.completion.assurance` now matches the stem to the version it builds, as the deliverables block already does (#1499).
