**A nation, country, region or continent name is no longer flagged as a personal name.** The generic `*_name` PII match now treats `nation`, `country`, `region` and `continent` as non-person qualifiers, so `nation_name` can be grouped by in a governed semantic query instead of being refused as PII. A bare `name`, a `customer_name`, an ambiguous `n_name` and a `city_name` (address data) are still flagged.
