**`transform apply`, `export`, `ground` and `classify` refuse an empty plan id and name the plan they pick.** Passing `""` as the plan id is now a clean `reason: request` refusal ("empty plan id; pass a plan id, or omit the argument...") instead of silently applying the latest unapplied plan. Omitting the id still applies the latest unapplied plan, but the envelope now says which one in `data.resolved_plan` (plan id, intent, creation time) and in a `warnings` line, so a caller whose plan id came back empty from a failed substitution can see what Dex chose.
