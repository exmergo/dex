**An argument dex cannot parse now prints an error envelope.** A missing argument, an unknown flag or command, or a bad value used to exit 2 with nothing on stdout, so a host could not tell it from a crash. It now prints one `reason: request` error envelope whose `errors` carry the parser's message (and the bare-subcommand tip when one applies) and exits 1 like every other error envelope. The usage still goes to stderr, and `--help` and a bare `dex` are unchanged.
