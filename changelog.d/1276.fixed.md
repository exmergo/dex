**`transform apply` of a Cube plan keeps file modes and runs the write-time rules.** An applied Cube model file used to become owner-only (`0600`), which showed up as a mode change in `git diff` and left the file unreadable to other users or a container; it now keeps its mode, and a new file gets the usual mode under the umask. Apply also runs the checks `semantic cube define|update|plan` stores a plan under, so a plan document applied in another checkout can no longer write a file with a key Cube refuses. (#1270)
