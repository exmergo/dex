**`explore relationships --verify` and `explore map --verify` no longer fail when the warehouse refuses one probed join.** A refused batch is retried edge by edge, so the joins the warehouse accepts are still measured; on ClickHouse, a join refused for lack of a common key type (signed against unsigned, for example Int32 against UInt64) is retried with both key sides compared as Int128. An edge that still refuses is reported in notes instead of failing the command.
