**`transform plan` skips an edit that matches the file on disk.** A payload that resent an unchanged file counted it as a change: an unchanged seed made `transform compare` return `inputs_unsynchronized` for the model the plan did change, and an unchanged model was offered a comparison the build then reported as `comparison_not_run`. An edit whose content matches the file on disk is now left out of the plan, its diffs, `paths`, the comparison offer and the seed and snapshot check, and one warning names the skipped files ("N edits match the tree and were skipped"). A payload whose every edit matches the tree is refused, since the plan would change nothing.
