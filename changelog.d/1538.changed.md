**`explore diagram` and `explore relationships` leave the Elementary package's own tables out, as `explore map` does.** Where a project installs `elementary-data/elementary`, `explore inventory --rank` and `explore map` already left the package's metadata tables out of ranking by their signature. The diagram still drew every one a cache held a profile for (after a `map --include-elementary` or a hand-run `explore profile`), and relationship inference profiled the whole inventory, package tables included, and inferred the joins among them, at a cost on a metered connector. Both now apply the same rule, with the same recogniser: `explore diagram` reads the signature over the cache's identifiers, names only, so it stays free, and draws none of the package's tables, `--full` included, with none of them counted as an elided entity (an edge onto one is counted in `elided_edge_count`, and connects nothing, so a project table whose only join is onto one is drawn only with `--full`); the signature has to be in the cache, so a lone package table profiled by hand into a cache only `explore relationships` has written, which holds no entry for the tables it left out (a `map` keeps their inventory entries, and no later write drops them), is drawn by `--full` until `explore map` writes the rest. `explore relationships` leaves them out before anything is priced or profiled, so its estimate prices none of them and no join among them is inferred, while a profile of one the cache already holds is left as it is and the joins among them an earlier `--include-elementary` run cached are dropped from the cache, as on `map` (carried from outside a narrower `--scope`, they stay in the cache and out of `data.relationships`, and `carried_relationship_count` counts only the carried joins the list reports). Only the package's own tables are left out, so a project table sharing their schema is still drawn and profiled. Each command reports `data.excluded` in the shape `map` does, always present, and a note names the namespaces and the way back: `--include-elementary` on either command draws or profiles them with the rest (#1494).
