**A Cube time bucket reads the same under `--api` and `--local`.** The same grouped query returned `2025-03-01T00:00:00.000` typed `time` when Cube executed it over `/v1/load`, and the warehouse's own spelling and type name when Dex ran Cube's SQL (`2025-03-01T00:00:00` typed `TIMESTAMP` on DuckDB, `2025-03-01T00:00:00+00:00` on BigQuery). Both paths now spell every bucket as a UTC ISO timestamp with an explicit offset, `2025-03-01T00:00:00+00:00`, typed `timestamp`, on every connector and at every grain, so switching `execution` or `semantic.deployment` no longer changes the cells or `types` of the time column (#1497).
