**A billed build's estimate says when the Elementary package makes it a floor.** `transform build` prices compiled nodes, and Elementary runs work no node shows: its `on-run-start` and `on-run-end` hooks, its monitoring tests' metric queries and tables over their `days_back` window, and its test materialization's failed-row count and sample query for each test it handles. Keyed off what the package does for the target (the resolver from #1305), never off whether it is installed, the ask, the over-ceiling refusal and the finished build now carry `cost.unpriced` (`elementary_hooks`, `elementary_monitoring_tests`, `elementary_test_extras`), the record under `data.unpriced` with each anomaly test's window, and one warning per kind. `cost.unpriced` is a new envelope field, `null` wherever nothing is claimed (#1309).
