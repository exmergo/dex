**`dex feedback`, and a report link on Dex's own failures.** `dex feedback` prints what a bug report or a feature request needs, with no project, connection or extra: the environment (versions, OS, and the connector and semantic-layer names your config writes; never a target, credential, path or value, so it can be pasted into a public issue as it stands) and links that prefill the issue forms from it. Nothing is sent. An error with `reason: internal`, an exception Dex did not anticipate, now carries `data.report`: a prefilled bug link naming the command, connector and exception class, never the error text. The issue forms add Trino, the semantic layer, how Dex is run and whether an agent filed on a person's behalf, and `SUPPORT.md` says where questions and security reports go. Reports drafted by your agent are welcome. (#1299)
