**`transform plan` no longer reports `aggregate_changed` when an aggregate only moves into a CTE.** Extracting an unchanged `count(*)` or `max(...)` into a CTE, with the final select reading its alias, was reported as an aggregate change even though the output still returned the same aggregate. The comparison now follows supported output aliases through CTEs before comparing aggregate semantics, so a pure move is silent while a genuinely changed aggregate, a DISTINCT change, or new `coalesce(..., 0)` behavior is still flagged.
