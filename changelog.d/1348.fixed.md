**A test Dex renders tells Elementary to keep no sample of its failing rows.** The `not_null`, `unique` and `relationships` tests Dex writes from a declaration, and the `not_null` and `unique` tests `maintain reconcile` adds, return key values when they fail, and where the Elementary package's test materialization runs, it copied up to `test_sample_row_count` of them into `test_result_rows`. Each of them now carries `config: {meta: {disable_test_samples: true}}`, which Elementary 0.20.0 and later honor and which does nothing without Elementary. Tests already in a project are left as written; only tests Dex adds carry the flag, so remove it in review to keep samples on a Dex test. dbt's own `store_failures` and Elementary's `tests_use_temp_tables` path are not affected (#1306).
