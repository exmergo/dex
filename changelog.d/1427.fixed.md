**The query firewall keeps every taint of an output name used twice, and checks every relation a statement names.** `SELECT a AS x, b AS x`, and a `*` over two sources that share a column, kept only the last projection's flags, so a flagged value could leave under a name a later, clean projection reused; the name now carries both. A relation the firewall refuses whole is now refused wherever the statement names it, including inside a scalar subquery a measuring aggregate reads. The exploration cache's schema version moves to 6, so a profile written before Elementary's row-value columns were withheld is profiled again before it is served (#1310).
