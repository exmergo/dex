**Three query-firewall paths no longer let a flagged value out.** An output name used twice (`SELECT a AS x, b AS x`, or one column in two sources under `*`) kept only the last projection's flags; the name now carries both. A set operation pairs columns by position, so where either side repeats a name its taints are merged across every column rather than paired by name. And a measuring aggregate no longer hides the subquery inside it: `SUM((SELECT x FROM t LIMIT 1))` is one value of `x`, so the subquery is resolved, its relations checked and its flags kept. A relation Elementary's schema holds whole is refused wherever a statement names it, cached or not, and a profile cached before this release drops any minimum, maximum or value domain of Elementary's row-value columns when it is loaded (#1310).
