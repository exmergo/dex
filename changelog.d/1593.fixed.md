**`maintain incidents` no longer says no failure has a known start when
Elementary dates it.** When dbt's `run_results.json` is from an invocation
Elementary also recorded (`placed: in_window`), the run-results note saying no
failure has a known start is left out, since a failure Elementary saw pass
before that run is dated from Elementary's runs. The note stays where the run
itself opened an incident with no known start (a test Elementary holds no
result for), and a run read alone, after Elementary's window, or with no place
in it keeps the note as before.
