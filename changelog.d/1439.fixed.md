**A mart whose grain is a single time column now derives a semantic model dbt parses.** The primary entity took the column's name, the same as the time dimension, so dbt rejected the model in any project that defines a metric. The entity is now named `<model>_<column>` with `expr: <column>`, numbered when a dimension or another entity already holds that name, and a mart that references it joins by that name wherever the plan lists the two.
