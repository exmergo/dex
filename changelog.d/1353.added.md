**`dex maintain coverage` annotates source freshness checks with their last
`sources.json` status.** Each source's `freshness` entry carries `last_run`
(`pass`, `warn`, `error` with `runtime error` mapped to `error`, or `not_run`
where the newest `sources.json` did not include that source), read from the
project's target path or Dex's isolated artifact directory (#1347).
`data.last_run` keeps describing the test run; `data.freshness_run` names the
`dbt source freshness` run apart with its own `invocation_id`, `generated_at`
and `age_seconds`, attributes only sources still enabled in the manifest, and
reads only each row's id and status.
