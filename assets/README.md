# Plugin icon

`icon.png` is the existing 192 x 192 Exmergo mark, copied unchanged from
https://www.exmergo.com/Exmergo-screenshots/Exmergo-Logo-Black-Transparent.png.
It is used for both the Codex composer icon and listing logo.
