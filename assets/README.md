# Plugin icon

`icon.png` is the existing 192 x 192 Exmergo mark, copied unchanged from
https://www.exmergo.com/Exmergo-screenshots/Exmergo-Logo-Black-Transparent.png.
It is used for both the Codex composer icon and listing logo.

# Preview image

`preview-dark.png` and `preview-light.png` are the README banner (the light one
is served unless the reader's GitHub theme is dark) and the repository's
social preview. Both are 2560 x 1280, GitHub's 1280 x 640 social card at 2x.

They are drawn in the trydex.ai style and made from source in
[exmergo/internal-marketing](https://github.com/exmergo/internal-marketing):
`dex/github-preview.html`, captured as is for the light image and with
`?theme=dark` (a blueprint) for the dark one.

# README section images

`readme/explore-*.png`, `readme/transform-*.png`, `readme/maintain-*.png`, and
`readme/semantics-*.png` illustrate the README's Explore, Transform, Maintain, and
Dex Semantics sections, each in a
light and a dark (blueprint) version for GitHub's two themes, at 2x the size
the README shows them. Their sources are `dex/readme/*.html` in
exmergo/internal-marketing.
