# Getting help with dex

- **Found a bug?** [Open a bug report](https://github.com/exmergo/dex/issues/new?template=bug_report.yml).
  Run `dex feedback` first: it prints the environment the report needs and a
  link that prefills the form. Nothing is sent.
- **Missing a capability, or working around one?** [Suggest an improvement](https://github.com/exmergo/dex/issues/new?template=feature_request.yml).
  A refusal that stopped a legitimate change, or a workaround you keep repeating,
  is worth a request.
- **A question about using dex?** Read the [documentation](https://docs.exmergo.com/dex),
  including [troubleshooting](https://docs.exmergo.com/dex/guides/troubleshooting),
  or ask in the [Discord community](https://www.exmergo.com/discord).
- **A security problem?** Never a public issue. Report it privately, as
  [SECURITY.md](SECURITY.md) describes.

Reports drafted by an agent on a person's behalf are welcome, under the same
rules as anyone's: search the existing issues first, include the smallest
reproduction, and never paste a credential, a raw row or a value. An agent
drafts the issue and asks the person before filing it, since an issue is public.
